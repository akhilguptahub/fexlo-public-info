# Fexlo — public website

This repository hosts the public website of **Fexlo**, a Chrome extension for collecting, comparing and exporting public product-catalogue data from websites you choose. It is published with GitHub Pages from the `main` branch.

* Website: https://akhilguptahub.github.io/fexlo-public-info/
* Install and get started: https://akhilguptahub.github.io/fexlo-public-info/install.html
* Compatibility and limits: https://akhilguptahub.github.io/fexlo-public-info/compatibility.html
* Privacy policy: https://akhilguptahub.github.io/fexlo-public-info/privacy.html
* Terms of use: https://akhilguptahub.github.io/fexlo-public-info/terms.html
* Support: https://akhilguptahub.github.io/fexlo-public-info/support.html

Fexlo is made by Akhil Gupta. It is in Early Access and free for now; future pricing has not been announced.

This repository contains static HTML, CSS and images only. The extension's source code is not published here. Support contact: akhil1998@gmail.com.
